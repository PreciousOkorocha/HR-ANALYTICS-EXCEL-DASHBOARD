# HR Workforce Analytics Dashboard (2026 Overview)
📌 Overview

Interactive HR analytics dashboard built in Excel to evaluate workforce structure, employee performance, engagement levels and training effectiveness.

This project converts raw HR data into decision-ready insights for workforce planning, performance optimization, and training evaluation.

⸻

🎯 Business Objective

Organizations often struggle to clearly understand:
	•	Workforce distribution across departments
	•	Employee engagement and satisfaction trends
	•	Training effectiveness and return on investment
	•	High vs low performer distribution
	•	Workforce demographics for planning decisions

This dashboard was built to centralize these metrics and support data-driven HR decisions.

⸻

📊 Dashboard Breakdown

1. Workforce & Demographics

Key Metrics
	•	Total Employees
	•	Average Age
	•	Gender Distribution
	•	Average Tenure

Key Insights
	•	Workforce is concentrated in Production
	•	Female employees represent a larger share of staff
	•	Employee base is skewed toward older age groups
	•	Younger employees remain underrepresented

⸻

2. Performance & Engagement

Key Metrics
	•	Engagement Score
	•	Work-Life Balance Score
	•	Employee Rating
	•	Satisfaction Score
	•	High Performer Count

Key Insights
	•	Production leads in overall performance output
	•	Engagement levels remain moderate across departments
	•	Field Operations records the highest satisfaction levels
	•	Low engagement slightly outweighs high engagement

⸻

3. Training & Development

Key Metrics
	•	Total Training Cost
	•	Training Programs Delivered
	•	Completion Rate
	•	Training Outcome Distribution

Key Insights
	•	High training spend is not matched by completion efficiency
	•	Training outcomes are evenly split across pass/fail/incomplete
	•	Internal and external programs require optimization
	•	Attendance does not consistently translate to effectiveness

This project uses a structured HR dataset prepared for analytical modeling.

Data Structure
	•	Raw Dataset: Contains unprocessed HR records with inconsistencies, missing values, and formatting issues.
	•	Cleaned Dataset: Processed version used for analysis after:
	•	Removing duplicates
	•	Handling missing values
	•	Standardizing categories
	•	Formatting numerical fields

Purpose

The transformation from raw to cleaned data demonstrates practical data preparation skills used in real-world HR analytics workflows.

Data Modeling (Pivot Tables)

Pivot tables were used to aggregate and structure HR metrics before visualization.

Key Pivot Outputs:
	•	Employee distribution by department
	•	Average engagement and satisfaction scores
	•	Training completion rates by program
	•	Performance segmentation across roles

These pivot tables served as the foundation for KPI cards and dashboard visuals.
